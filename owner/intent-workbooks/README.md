## How to use it

No order. No completeness. Open whichever door interests you, answer one
question or rewrite a whole page, and leave the `DERIVED` and `PROPOSED` lines
in place even where you disagree — contradicting them in your own words tells
the next agent what it got wrong, which a clean page does not.

Everything here is plain Markdown, editable in any text editor or straight in
GitHub's web editor on a phone. No tool is required to answer anything.
