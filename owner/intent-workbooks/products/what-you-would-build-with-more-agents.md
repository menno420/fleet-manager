# What you would build if the agents were better

## My current understanding

`VERIFIED`: you have described the direction you are testing — *"preferably I
would like to be able to do everything just from the chat, by telling my agents
what the desired end goal is"*, and you are *"trying to find out just how much
I can ask my agents to do before I need to step in."*

`DERIVED`: that is a capability experiment, not a product plan. It tells an
agent how you want to work but not what you would point that capability at.

`PROPOSED`: this page is the deliberately unconstrained one. Everything else in
this collection asks you to describe what exists; this asks what you would do
if the constraint you are currently testing turned out not to bind.

## Questions for you

1. If you could describe a whole product in one message and get it built
   properly, what would you ask for first?
2. What have you wanted to build and not started because it looked too big?
3. Is there an idea you have had more than once over the past year?
4. What is something you would build purely because it would be funny or
   interesting, with no other reason?
5. What do you think agents will be able to do in a year that they cannot do
   now — and what would you do with that?
6. Is there a thing you keep almost building and then abandoning? What is it?
