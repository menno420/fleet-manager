# The working contract between you and your agents

`VERIFIED`: the estate-level workbook already has one page on this
(`estate/how-agents-should-work-with-you.md`). `DERIVED`: one page is not
enough, because "how agents should work with you" is really nine separate
questions and they have different answers.

`VERIFIED`: on 2026-08-31 you set the standard these pages exist to make
concrete — agents should *"take initiative to leave the repo(s) in a better
shape than before and to help make the next agent's task easier"*, and you want
to direct work by stating a desired end goal and have the agent find and execute
the steps to reach it.

`PROPOSED`: answers here are the ones most likely to become **enforced**
mechanisms rather than prose — hooks, checks and routed reminders. That is
deliberate: `docs/intent.md` § 4 says instructions may not grow, only
mechanisms may.
